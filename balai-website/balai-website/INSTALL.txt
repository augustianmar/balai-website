BALAI PREMIUM V6.4 — INSTALLATION

1. Open the existing inner balai-website folder used by GitHub Pages.
2. Copy every file and folder from this package directly into that folder.
3. Choose Replace all when asked.
4. Commit to main and Push origin in GitHub Desktop.
5. Wait for GitHub Pages to deploy, then refresh the website with Ctrl + F5.

IMPORTANT
- Do not copy the enclosing download folder into balai-website.
- Keep the folder names and file names unchanged.
- The contact form remains intentionally disconnected until a confirmed BALAI email or form endpoint is added to assets/js/config.js.
