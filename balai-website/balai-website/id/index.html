Kesenjangan akses pasar

Potensi mudah terlihat.
Akses lebih sulit dibangun.

Sebagian besar proyek lintas pasar tidak berhenti karena peluangnya tidak terlihat. Proyek berhenti ketika konteks lokal, kualitas mitra, dan kesinambungan komersial tidak tersedia.
