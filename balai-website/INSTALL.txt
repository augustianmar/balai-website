BALAI PREMIUM V9.3 — INSTALLATION

1. Extract the update ZIP.
2. Replace the existing balai-website folder in your GitHub repository with the balai-website folder from the ZIP.
3. Commit and push the replacement.
4. Wait for GitHub Pages to deploy.
5. Refresh with Ctrl + F5 if necessary.

The correct published entry file remains balai-website/index.html.
